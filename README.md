# bailudu-zupu

白鹭渡许氏宗谱数字化，顺带给水府庙做的网站。

- `site/` 网站代码（族谱查询 + 中元放灯登记）
- `scans/` 卷三影像
- `docs/` 凡例
- `lanterns/` 放灯登记数据。网站表单提交后，用 `bailudu-temple` 账号自动提交，提交时间就是登记时间。2025 年的数据是照纸本登记簿补录的。

## 查登记记录

陈伯要查哪盏灯是哪天几点、用哪个账号登的：打开 `lanterns/2026.csv`，点右上角的 **History**，每一条提交就是一次登记或撤灯，标题里写着登记时间（北京时间）。

## 账号

网站后台账号由水府庙管事保管。管事不在时交给理事代管，用后台登的灯，提交说明里写“来源：后台”。

## 说明

族谱只录大名，乳名不录，见 `docs/凡例.md`。
